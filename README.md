# 🐍 Estudos e Projetos em Python

Bem-vindo ao meu repositório de estudos em **Python**!

Este espaço reúne exercícios, experimentos e pequenos projetos desenvolvidos durante minha formação em **Análise e Desenvolvimento de Sistemas**.

O objetivo é registrar minha evolução na programação, praticando desde conceitos fundamentais até o desenvolvimento de aplicações.

## 📁 Organização do Repositório

O conteúdo está dividido em duas categorias principais:

### 📘 Fundamentos

Exercícios voltados ao aprendizado dos conceitos essenciais de programação.

| Exercício | Conteúdo |
|---|---|
| Fibonacci | Sequências e estruturas de repetição |
| Tratamento de Erros | Exceções e validação de entradas |
| Escolher Filmes | Estruturas condicionais |
| Enumerar Nomes | Listas e iteração |

Pequenas aplicações para colocar em prática os conhecimentos adquiridos.

| Projeto | Descrição |

## 🛠️ Tecnologias e Conceitos

- Python 3
- Programação orientada a objetos

- Manipulação de listas e dicionários
- Interfaces gráficas com Tkinter

## ▶️ Como Executar

**1.** Instale o Python 3.

**2.** Clone este repositório:

```bash
git clone https://github.com/Jabu-BG/Codigos-em-Python.git
```

**3.** Entre na pasta:

```bash
cd Codigos-em-Python
```

**4.** Execute um exemplo:

```bash
python fundamentos/fibonacci.py
```

Alguns projetos utilizam interfaces gráficas ou podem precisar de dependências adicionais.
